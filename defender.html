Si la configuración de protección contra manipulaciones está activada, no podrás desactivar el servicio antivirus Microsoft Defender mediante la clave de política de grupo DisableAntiSpyware

Esta es una clave de registro protegida por lo que no te permitirá cambiarla manualmente ni usar un archivo REG. Sí, también tengo 5 cuando está ACTIVO. Pero cuando está DESHABILITADO, tengo 4 en lugar de 0. Lo que podría explicar por qué AntiVirus se habilitó nuevamente por sí solo después de un reinicio.

Para deshabilitar la protección contra manipulaciones (Tamper protection) mediante el registro, la subclave del registro "TamperProtection", ubicada en HKLM\SYSTEM\CurrentControlSet\Services\WinDefend\Start debe configurarse entre 5 y 0/4.

No es posible modificar los valores de la subclave del registro en HKLM\SYSTEM\CurrentControlSet\Services\WinDefend
ni siquiera con privilegios SYSTEM/TrustedInstaller, ya que Windows Defender tiene un controlador en modo kernel (WdFilter.sys) que registra un filtro de devolución de llamada del Registro que protege las claves de registro de Defender.

WinDefCtl .: protección contra manipulaciones (Tamper Protection)

WinDefCtl
Control automatizado de Windows Defender (Windows 11) y protección contra manipulaciones (Tamper Protection) mediante la automatización de la interfaz de usuario (UI)

¿Qué es?

WinDefCtl es una utilidad de línea de comandos que automatiza el control de la configuración de Protección en Tiempo Real (RTP) y Protección contra Manipulaciones (Tamper Protection) de Windows Defender.
A diferencia de los métodos tradicionales (PowerShell, Registro), utiliza la API de Automatización de la IU para interactuar con la interfaz de Seguridad de Windows, simulando eficazmente los clics humanos a la velocidad de una máquina.

¿Por qué Automatización de la IU?

Cuando la Protección contra Manipulaciones está habilitada, Microsoft bloquea todos los métodos administrativos tradicionales:
PowerShell: Set-MpPreference -DisableRealtimeMonitoring $true se ignora
Registro: Modificación directa bloqueada por el controlador ELAM
Único método autorizado: GUI de Seguridad de Windows (Windows Security GUI)

WinDefCtl
Cubre esta brecha automatizando la capa GUI mediante las interfaces COM de accesibilidad de Microsoft (IUIAutomation), a la vez que utiliza el ocultamiento de DWM para mantener la ventana invisible durante el funcionamiento.

Características:
Activar/Desactivar la protección en tiempo real
Activar/Desactivar la protección contra manipulaciones
Comprobar el estado de la protección
Operación invisible (ocultamiento de DWM + posicionamiento fuera de pantalla)
Gestión automática del Control de Cuentas de Usuario (UAC) (copia de seguridad ? suprimir ? restaurar)
Detección de arranque en frío con precalentamiento
Independiente del idioma (probado en Windows 11 25H2 EN/PL)

Uso:
Codigo:
# Real-Time Protection
./WinDefCtl.exe rtp status # Chequeo Estatus
./WinDefCtl.exe rtp on # Activado
./WinDefCtl.exe rtp off # Desactivado
# Tamper Protection
./WinDefCtl.exe tp status # Chequeo Estatus
./WinDefCtl.exe tp on # Activado
./WinDefCtl.exe tp off # Desactivado


Detalles técnicos:

La herramienta funciona así:
1. Abrir la URI windowsdefender://threatsettings
2. Ocultar la ventana mediante ocultación multicapa (opacidad=0, ocultación DWM, teletransporte fuera de pantalla) (multi-layer hiding (opacity=0, DWM cloak, off-screen teleport)
3. Usar la automatización de la interfaz de usuario (UI) para localizar los interruptores en el árbol de elementos
4. Suprimir temporalmente las solicitudes del Control de Cuentas de Usuario (UAC) mediante el intercambio del registro
5. Activar y desactivar los estados de protección y verificar los cambios en la interfaz de usuario (UI)

Requiere una sesión de interfaz de usuario (GUI); no se puede ejecutar sin interfaz gráfica ni con RDP minimizado, ya que necesita la aplicación Windows Security UWP para renderizar y responder a los comandos de automatización.

Pruebas:
Probado en Windows 11 25H2 (inglés y polaco). Diseñado con detección de elementos independiente del idioma, por lo que debería funcionar en todas las configuraciones regionales de Windows 11.
